# 2026-06-09 | ARIMAX 학습 노트

## 오늘 한 것
서울 아파트 가격 분석에 ARIMAX(1,0,0)을 적용했다.  
다중회귀의 자기상관 문제(DW=0.292)를 AR(1) 항으로 모형 내에서 해결했다.

---

## 오늘 배운 핵심 개념

### 1. 모형이란 무엇인가
> 현실을 단순화한 설명 기계

- 복잡한 현실을 하나의 규칙으로 압축한 것
- 모형은 항상 틀린다. 중요한 것은 **얼마나 체계적으로 틀리는가**

### 2. 자기상관이란
- 이번 달 오차가 다음 달 오차에 영향을 미치는 것
- DW 통계량으로 진단 (2=독립, 0=강한 양의 자기상관, 4=강한 음의 자기상관)
- 집값처럼 **관성**이 있는 데이터에서 자주 발생

### 3. ARIMA 세 부품

| 부품 | 의미 | 역할 |
|---|---|---|
| AR(p) | AutoRegressive | 과거의 나 자신이 설명변수 |
| I(d) | Integrated | 차분 횟수 (비정상성 제거) |
| MA(q) | Moving Average | 과거 오차가 현재에 영향 |

### 4. ARIMAX = ARIMA + 외생변수(X)
- 기존 회귀의 설명변수(금리, CSI 등)를 그대로 유지
- AR 항을 추가해 관성을 모형 안에서 직접 처리

### 5. ACF / PACF 읽는 법

```
ACF  → 천천히 감쇠 = AR 구조 존재
PACF → lag k에서 절단 = AR 차수는 k
```

오늘 데이터: PACF가 lag 1 이후 절단 → AR(1) 선택

## 오늘의 핵심 발견

**윤석열 더미가 HAC에서는 유의(p=0.012)했지만 ARIMAX에서는 소멸(p=0.457)**

해석: 해당 시기의 집값 상승은 정권 고유의 효과가 아니라,  
**주담대금리 + 집값 관성**으로 이미 설명되는 움직임이었다.

→ 모형이 자기상관을 제대로 처리하지 못하면 결론 자체가 바뀐다.

| 변수 | 계수 | 해석 |
|---|---|---|
| 주담대금리 | −0.624 | 금리 1%p↑ → 집값 변동률 −0.62%p |
| CSI | +0.020 | 심리적 기대가 독립적으로 작용 |
| ar.L1 | +0.765 | 지난달 관성의 76.5%가 이번 달로 이어짐 |

## 복습 필요 개념 (다음 세션 전)

- [ ] **ACF / PACF 읽기** — 막대 그래프에서 차수를 어떻게 결정하는가
- [ ] **AR / MA / I의 차이** — 각각 언제 필요한가
- [ ] **DW 통계량 해석** — 왜 2가 이상적인가, 0과 4는 무엇을 의미하는가
- [ ] **잔차 진단 지표 3종**
  - Ljung-Box: 잔차에 자기상관이 남아있는가
  - Jarque-Bera: 잔차가 정규분포인가
  - Heteroskedasticity: 분산이 시간에 따라 일정한가

## 아직 해결되지 않은 문제

- Heteroskedasticity — 시기별 변동성 차이 존재
- DW=1.662, 목표 2.0에 아직 미달
