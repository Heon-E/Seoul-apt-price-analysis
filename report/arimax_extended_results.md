## 2. 핵심 발견

### ① 전세가격지수가 가장 중요한 누락변수 (AIC 17.4p 개선)
- M1 → M2: AIC 86.7 → 69.3 (**-17.4p**)
- M1 → M3: AIC 86.7 → 70.9 (-15.8p)
- 전세가격지수 추가 시 가장 큰 모형 개선 → **기존 모형의 누락변수 편향 확인**

### ② 전세가격지수의 부호 (-)
```
M2: jeonse_index β = -0.0055  (p=0.217, 통계적 비유의)
M5: jeonse_index β = -0.0129  (p=0.062, 10% 유의*)
```
- 전세가격↑ → 매매가격↓ 방향: **전세-매매 대체 효과** (전세가 높아지면 매매 수요 일부 흡수)
- 하지만 M2에서 통계적으로 비유의 → 방향성 참고 수준
- M5에서 10% 유의: 다른 변수 통제 후 더 뚜렷하게 나타남

### ③ 주담대 잔액 효과 미미
```
M3: mortgage_balance β = -0.0000  (p=0.982, 비유의)
```
- 주담대 잔액 자체는 유의하지 않음
- 해석: 주담대 **규모**보다 **금리**(mortgage_rate)가 매매가격에 더 직접적 영향
- 또는 주담대 잔액이 가격의 결과변수이기도 하여 내생성 문제 존재

## 3. 선행연구와의 비교

| 항목 | 우리 분석 (ARIMAX M2) | 선행연구 |
|------|----------------------|---------|
| 금리 효과 | -0.36%p/1%p | -4.5%/년 (OECD) |
| 전세가 효과 | -0.0055 (비유의) | +0.655 (최창호 2022, 1개월 유의) |
| 자기상관 처리 | AR(1) 내생화 | Cochrane-Orcutt 사후보정 |
| AIC 개선 | -17.4p (전세가 추가) | - |

**해석**: 선행연구(최창호 2022)는 전세가 1% 상승 → 매매가 +0.655% 양(+) 효과를 보고했으나, 우리 모형은 음(-) 방향. 이는 **통제변수 차이**: 선행연구는 금리·CSI를 통제하지 않아서 전세가↑가 매매수요 증가로 잘못 해석될 수 있음.

## 4. 결론 및 한계

**결론:**
- 전세가격지수 추가로 모형 적합도 유의하게 개선 → 누락변수 편향 부분적으로 해소
- 주담대 잔액보다 **금리 수준이 직접적인 정책 변수**
- 전세가 효과: 대체 효과(전세↑→매매 수요 일부 전환) 방향이나 통계적으로 불안정
- 최적 모형: **BIC 기준 M2** (전세가격지수 하나만 추가하는 것이 가장 효율적)

**한계:**
1. `jeonse_ratio`의 절대 수준이 실제 전세가율(60-75%)과 다름 (기준년도 불일치)
2. 주담대 잔액의 내생성 문제 (가격↑→대출↑ 역인과)
3. OLS 근사 추정 (State Space Model 대비 효율성 손실)
4. 전세가격지수의 유의성이 낮아 추가 검토 필요 (패널 데이터, 구조방정식 등)
