# 도쿄 맨션 가격 분석 — 학습 노트

> 분석 기간: 2010년 1월 – 2024년 12월 (180개월)  
> 데이터 출처: MLIT(가격지수), BOJ Stat(통화량·PPI·환율), 내장(닛케이225)

---

## 1. 분석 배경 및 목적

### 왜 도쿄인가?
서울 아파트 분석과 동일한 방법론(ARIMAX)을 일본에 적용해, **"제로금리 국가에서 집값은 어떻게 움직이는가"** 를 이해하는 것이 목적. 일본은 아베노믹스(2013~) 이후 무제한 양적완화와 마이너스 금리(-0.1%, 2016~2024)를 실험한 유일한 주요 국가이므로, 통화정책이 자산가격에 미치는 영향을 분리해서 보기에 적합한 사례.

### 분석 대상
- **MLIT 도쿄 맨션 가격지수**: 2010년=100 기준, 2024년 12월 기준 약 220 (14년간 2.2배 상승)
- MoM% (전월 대비 변화율) 기준으로 ARIMAX 추정, Level 기준으로 공적분 검정

## 3. 이상함을 느꼈던 포인트 (직관 vs. 모형)

### 3.1 "엔화는 들쭉날쭉인데 집값은 꾸준히 오른다"
분석 2세션째에 사용자가 그래프를 보고 직접 지적한 핵심 관찰.

- **모형이 주장한 것**: USD/JPY 상승 (엔화 약세) → 외국인 투자 유입 → 집값 상승
- **사용자가 느낀 이상함**: 환율이 강세로 돌아설 때 집값이 내려야 하는데, 2012년 이후 환율은 오르내렸어도 집값은 단 한 번도 전년 동기 대비 하락한 적이 없음
- **결론**: 스퓨리어스(허위) 상관. 두 시리즈가 2010-2024년 동안 동시에 우상향한 것은 **아베노믹스라는 공통 시대 배경** 때문
- **검증**: Engle-Granger 잔차 ADF t=-2.1 → 공적분 불성립으로 확인

### 3.2 "변수를 계속 추가해도 R²가 오르지 않는다"
ARIMAX 전수 탐색(16 조합): 최적 AIC 모형은 `mb_yoy + usdjpy`. 닛케이, PPI 추가해도 AIC 개선 없음.

- **의미**: 거시 지표의 단기 변동(flow)으로는 맨션 가격의 월간 변화를 설명하기 어려움
- **73% 미설명 분산**: 14년 장기 우상향 추세는 현재 수집한 어떤 변수로도 설명 불가

### 3.3 공적분도 불성립 — "뭔가 빠진 변수가 있다"
7가지 변수 조합 전부 Engle-Granger 검정 실패.

- 가장 강력한 후보인 log(MB) + log(PPI) + USD/JPY 조합도 t=-3.30 (임계값 -4.10 미달)
- **결론**: 도쿄 맨션 가격은 본원통화·환율·PPI와 장기 균형 관계가 없음
- 통화 팽창이 집값을 올린다는 직관적 스토리는 우리 데이터 내에서 계량적으로 지지되지 않음

## 4. 방법론 설명

### 4.1 ARIMAX

**기본 식**:

    y_t = c + phi_1 * y_{t-1} + beta_1 * X_1t + beta_2 * X_2t + e_t

- y_t: 맨션 MoM% (전월 대비 변화율)
- phi_1: AR(1) 계수 — 지난달의 영향이 이번 달에 얼마나 지속되는가
- beta: 외생 변수의 영향력 크기
- 추정 방법: OLS (numpy.linalg.lstsq)

**왜 MoM%를 쓰는가?**  
가격 Level은 단위근(I(1))이 있어 OLS 회귀가 허위 결과를 낳음. MoM%로 변환하면 정상(stationary) 시리즈가 되어 표준 OLS 적용 가능.

**AIC**: AIC = -2*ln(L) + 2k  
변수를 추가할수록 k가 늘어 패널티를 받음. 낮을수록 좋음.

---

### 4.2 ADF 단위근 검정

**질문**: 이 시리즈는 평균으로 회귀하는가(정상), 아니면 영원히 떠돌아다니는가(비정상)?

**검정식**:

    delta_y_t = alpha + gamma * y_{t-1} + sum(delta_i * delta_y_{t-i}) + e_t

- H0: gamma = 0 → 단위근 존재 (비정상, I(1))
- H1: gamma < 0 → 단위근 없음 (정상, I(0))
- 5% 임계값: t < -2.86 이면 H0 기각 (정상)

**이번 분석 결과**:

| 시리즈 | Level | 1차 차분 | 판정 |
|--------|-------|----------|------|
| log(맨션지수) | +1.34 | -22.7 | I(1) |
| log(본원통화) | -2.30 | -4.89 | I(1) |
| USD/JPY | -0.16 | -5.30 | I(1) |
| log(PPI level) | +1.36 | -8.28 | I(1) |
| 실질금리 | -2.45 | -4.57 | I(1) |

---

### 4.3 Engle-Granger 공적분 검정

**질문**: 두 I(1) 시리즈가 장기적으로 같은 방향으로 움직이는 구조적 관계가 있는가?

**2단계 절차**:
1. 장기 수준 회귀: log(mansion)_t = alpha + beta_1 * X_1t + beta_2 * X_2t + u_t
2. 잔차 ADF: u_t가 정상(I(0))이면 공적분 관계 성립

**임계값이 일반 ADF보다 엄격한 이유**: 회귀 잔차는 이미 "가장 잘 맞게" 피팅된 것이므로, 단순 ADF보다 강력한 기준 필요.
- 독립변수 1개: -3.34
- 독립변수 2개: -3.74
- 독립변수 3개: -4.10

**이번 결과 (7개 조합 모두 불성립)**:

| 조합 | 잔차 ADF t | 임계값 | 판정 |
|------|------------|--------|------|
| log(MB) | -0.28 | -3.34 | 불성립 |
| log(PPI) | -1.46 | -3.34 | 불성립 |
| USD/JPY | -2.11 | -3.34 | 불성립 |
| log(MB) + USD/JPY | -1.74 | -3.74 | 불성립 |
| log(MB) + log(PPI) | -3.17 | -3.74 | 불성립 |
| log(PPI) + USD/JPY | -1.95 | -3.74 | 불성립 |
| log(MB) + log(PPI) + USD/JPY | -3.30 | -4.10 | 불성립 |

---

### 4.4 ECM (Error Correction Model)

**공적분이 성립했다면** 사용하는 모형. 단기 변동과 장기 균형 이탈을 동시에 설명.

    delta_log(mansion)_t = alpha + gamma * ECT_{t-1} + beta_1 * delta_X_1t + beta_2 * delta_X_2t + e_t

- **ECT (Error Correction Term)**: 장기 균형에서의 이탈량 = u_{t-1}
- **gamma**: 균형 회귀 속도. 음수여야 함.
  - 예) gamma = -0.035 → 이탈의 3.5%씩 매월 수렴, 반감기 19개월

**이번 결과**:

| 모형 | R² | AIC | ECT 유의성 | 비고 |
|------|----|-----|------------|------|
| ECM v1 (MB+FX) | 0.096 | -950.31 | *** | 공적분 불성립이라 해석 주의 |
| ECM v2 (MB+PPI) | 0.072 | -945.65 | *** | 공적분 불성립이라 해석 주의 |
| ECM v3 (+실질금리) | 0.100 | -949.20 | *** | — |
| ARIMAX+실질금리 | 0.037 | -939.06 | — | 실질금리 p=0.96 |

> **주의**: 공적분이 성립하지 않으면 ECT를 포함해도 이론적 근거가 약함. ECT가 유의하게 나오는 것은 부분적으로 잔차의 공통 추세를 흡수하는 효과.

## 5. 모형 성능 최종 요약

최고 성능 ARIMAX: **mb_yoy + usdjpy, R²=0.270**  
- 이 모형도 월간 변화의 73%를 설명 못함

미설명 분산(73%)의 잠재적 원인:
1. **공급 변수 부재**: 도쿄 신규 맨션 착공 건수 (MLIT 건축착공통계)
2. **도시 집중화**: 도쿄 인구 순유입 (지방 소멸 → 도쿄 수요 구조 증가)
3. **기관 투자**: J-REIT 총자산 또는 부동산 펀드 설정잔고
4. **인구 구조**: 단카이 세대 은퇴 + 도쿄 집중이 특수 수급 구조 형성

### 이 한계가 주는 분석적 시사점

공급 변수를 끝내 추가하지 못한 것은 단순 기술적 제약이지만, 이 상황 자체가 중요한 시사점을 담고 있습니다.

**도쿄 맨션 가격 상승의 73% 미설명 분산에 대한 가설:**

거시 유동성 변수(통화량, 환율, PPI, 실질금리, 닛케이)로 설명 불가능한 이 73%는 아마도 다음 두 변수의 상호작용에서 기인합니다:

1. **공급 제약 (Supply Constraint)**  
   도쿄 도심부 토지 가용성 감소 → 신규 착공 감소 → 공급 부족  
   이 메커니즘은 단순한 월별 유량(flow) 변수가 아닌 **누적 스톡의 구조적 부족**으로 나타나므로, ARIMAX 같은 단기 변동 모형으로는 포착하기 어려움

2. **도시 집중화의 구조적 가속 (Structural Urbanization)**  
   지방 소멸 + 도쿄 집중 → 수요 기반의 장기 팽창  
   이 역시 월별 변화보다 수십 년에 걸친 구조적 추세로, 단기 시계열 모형의 한계

**계량적 교훈:**  
"설명 못 하는 분산"을 줄이려고 변수를 계속 추가하는 것보다, 그 미설명 분산이 **왜 설명 불가능한지**를 이론적으로 해석하는 것이 더 유익한 접근일 수 있음.

도쿄 맨션 시장의 14년 상승은 월별 거시 지표보다 **도시계획·인구구조·토지공급**이라는 구조적 요인으로 설명하는 것이 더 설득력 있으며, 이는 서울과의 비교에서 핵심 대조점이 됨.

## 9. 최종 결론 — 도쿄 분석 종합

### 핵심 발견 3가지

**① 거시 유동성은 단기 변동은 설명하나 장기 추세는 설명하지 못한다**  
- ARIMAX 최고 모형 R²=0.270 → 월간 변화의 27%만 설명
- 아베노믹스의 통화량 폭발(2013년 이후 MB 6배 증가)도 집값 상승률과 공적분 없음

**② 스퓨리어스 상관의 함정**  
- "엔화 약세 → 외국인 투자 → 집값 상승" 스토리는 계량적으로 지지 불가
- 사용자의 직관("엔화는 들쭉날쭉인데 집값은 꾸준히 오른다")이 정확했음
- 모든 변수 조합에서 Engle-Granger 공적분 불성립 → 공통 시대 배경(아베노믹스) 외에 구조적 연결고리 없음

**③ 거시 모형의 구조적 한계**  
- 도쿄 집값의 핵심 드라이버는 월별 거시지표가 아닌 도시 집중화 + 공급 제약
- 이 두 요인은 ARIMAX나 ECM 같은 단기 동학 모형으로 포착 불가능
- 적절한 분석틀은 패널 데이터 모형(도시별 비교) 또는 도시경제학적 균형 모형일 것

### 서울 분석과의 핵심 대조

| | 서울 | 도쿄 |
|--|-----|-----|
| 주요 드라이버 | 규제·대출(전세가율, 주담대) | 구조적 수급(추정) |
| 거시변수 설명력 | 상대적으로 높음 | 매우 낮음(R²=0.27) |
| 금리 영향 | 강함 | 거의 없음(제로금리 환경) |
| 공적분 관계 | 미확인 | 불성립 |
| 정책 함의 | 대출 규제가 가격 안정에 유효 | 공급 확대 없이 가격 안정 불가 |
